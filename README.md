# 🏆 Maratona de Programação — Beecrowd (Iniciante)

Repositório dedicado à resolução de problemas da categoria **Iniciante** da plataforma [Beecrowd](https://www.beecrowd.com.br/) (antigo *URI Online Judge*). 

O objetivo deste repositório é documentar a evolução lógica e a implementação de algoritmos utilizando diferentes linguagens de programação: **Java**, **Python** e **C/C++**.
